## Building before the event

The global FAQ says teams may not start working on challenges before the hackathon. The Bangladesh guide asks for a **concept-only** Video 1. So this repository contains **only concept work**: ideas, plans, test rules and data lists. All code is written during the event, and the git history will show it.

## Our three videos

| Video | Length | Must contain | Where |
|---|---|---|---|
| 1 · Prescreening | ≤ 240 s | Team name; every member by name; problem and challenge; **solution concept** | YouTube → Bangladesh portal |
| 2 · Local judging | ≤ 240 s | All of the above + **working demo** + **NASA data named out loud** | YouTube → form; file → Local Lead's Drive folder |
| 3 · Global judging | ≤ 30 s | Team, members, problem, solution + demo, NASA data | YouTube/Vimeo → form **and** NASA project page |

Hard rules: over-length videos are cut off; name every member every time; credit any third-party or generated content; **English subtitles** on demos; **no recognisable names, voices or faces of anyone under 18**.

## Eligibility for awards

- Answer one official 2026 challenge, named on the project page
- Link a **public** repository (test it in a private window)
- Use **NASA open data** (not optional)
- Keep event code **open source**
- Every team member registered on the NASA team page with a role
- Team of 1–6; one event per person

Maximum 118 before the bonus. Local winners: up to 2 per city. Global nominations: 1 per 10 projects submitted.

## NASA project page checklist (14 Nov)

- [ ] High-Level Summary, with links to Video 2 and this repository
- [ ] Project Demo: Video 3 (≤ 30 s), or a 7-slide deck as the accepted alternative
- [ ] Final Project: this repository and the live site
- [ ] Project Details: the why/what/how; community benefit; tools and technologies
- [ ] **Use of AI:** every AI tool used, named, with prompts, reasons and the data it worked on
- [ ] **NASA data sources used:** every dataset and what it was used for ([`nasa-data.md`](nasa-data.md))
- [ ] References: every source, paper, dataset, library and asset
- [ ] Every member listed with photo and role; team photo
- [ ] **Submit clicked.** An unsubmitted page is not judged
